# Save space with selective sync and online-only files

You don't have to keep every Nimbus file on your computer. Two features help you save disk space.

## Selective sync

Selective sync lets you choose which folders appear on this computer at all. Go to **Preferences > Sync > Choose folders** and untick folders you don't need here. They disappear from this computer but stay safe in your account and on your other devices.

## Online-only files

With online-only files, every file and folder appears on your computer, but only takes up space when you open it. A cloud icon means the file is online-only. When you open it, Nimbus downloads it on demand, and it shows a green tick.

- Right-click a file and choose **Make online-only** to free up its space.
- Choose **Always keep on this device** for files you need when you're offline, for example before a flight. These show a solid green circle.

Online-only files need an internet connection to open. Online-only files are available on Windows 10 and later and macOS 12.3 and later; on Linux, use selective sync.

## Which should I use?

Use online-only files if you want to see everything and save space. Use selective sync for folders you never use on this computer, such as another person's shared projects.
