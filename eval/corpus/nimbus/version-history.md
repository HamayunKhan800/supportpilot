# Restore an earlier version of a file

Every time a file changes, Nimbus keeps the previous version. If you overwrite something by mistake, or a file gets damaged, you can go back.

## How long versions are kept

- **Free:** 30 days
- **Personal and Family:** 180 days
- **Business:** 365 days

Older versions **don't count** toward your storage.

## Restore a version

1. In the web app, right-click the file and choose **Version history**. In the desktop app, right-click the file and choose **Nimbus > Version history**.
2. Pick a version by its date and time. You can preview it before restoring.
3. Click **Restore**. The restored version becomes the newest version; nothing is lost, because the current version is kept in the history too.

You can also click **Download** to get an old version as a separate copy, without changing the current file.

## Recover from ransomware

If ransomware or a virus encrypted many files on your computer, those damaged files were synced too. Use **Rewind** under **Settings > Files > Rewind** to restore a whole folder, or your entire Nimbus space, to how it was at a chosen moment. Rewind is available on Personal, Family and Business plans.
