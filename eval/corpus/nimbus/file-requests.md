# Collect files with a file request

A file request lets anyone upload files to a folder of your choice, even if they don't have a Nimbus account. It's perfect for collecting homework, photos from an event, or documents from a client. File requests are available on Personal, Family and Business plans.

## Create a file request

1. In the web app, click **File requests** in the sidebar and then **New request**.
2. Give it a title and choose the folder where uploads should go.
3. Optionally set a **deadline**. After the deadline the request closes automatically, or you can allow late uploads, which are marked as late.
4. Copy the link and send it to people, or enter their email addresses and we'll send it for you.

## What uploaders see

Uploaders see the title and an upload button, plus a field for their name. They **can't see** the folder or any other files in it, including files uploaded by others.

## Storage and limits

Uploaded files count toward your storage, because you own them once they arrive. Each uploaded file can be up to 50 GB. If your storage is full, the request stops accepting files.

## Close a request

Open **File requests**, select the request and click **Close request**. Files that were already uploaded stay in your folder.
