# Conflicted copies

A conflicted copy is created when the same file is changed in two places before Nimbus can sync the changes, for example when you edit a document on your laptop while offline and a colleague edits it at the same time.

## What you see

Nimbus never throws away anyone's changes. It keeps one version under the original name, and saves the other as a separate file with the device name and date in it, like this:

report (Conflicted copy from Sam's laptop 2026-03-02).docx

## How to resolve it

1. Open both files and compare them.
2. Copy the changes you want to keep into the original file.
3. Delete the conflicted copy.

## Working offline

Changes you make while offline are uploaded as soon as you reconnect. If nobody else changed the same file in the meantime, there's no conflict.

## Avoid conflicts

- For Office documents, use **Open in Microsoft 365** from the web app. Several people can edit at the same time without conflicts.
- Close files on one device before editing them on another.
- Make sure the desktop app is running and up to date on every computer, so changes sync quickly.
