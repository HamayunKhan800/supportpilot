# Data classification

> M7 step 5 (finding M7-15, ASVS V14.1.1 and V14.1.2) · 2026-10-25. Which data the app holds, how sensitive it is and how it is protected. The public demo holds synthetic data only.

## Levels

| Level            | Meaning                                                                       |
| ---------------- | ----------------------------------------------------------------------------- |
| **Secret**       | Gives access by itself. Never stored readable, never logged, never displayed. |
| **Confidential** | Personal data or a workspace's private content. Only its workspace sees it.   |
| **Internal**     | Operational data with no personal content.                                    |
| **Public**       | Meant to be seen by anyone.                                                   |

## Inventory

| Data                                            | Level        | Stored in                                                     | Protection                                                                                                                                                                                                                     |
| ----------------------------------------------- | ------------ | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

| Google and GitHub tokens                        | Secret       | `account` (encrypted)                                         | XChaCha20-Poly1305; never used by the app                                                                                                                                                                                      |

## Rules that follow

- **Secret** data is stored hashed or encrypted and goes only in request bodies or HttpOnly cookies, never in URLs (tracking and reset links are the documented exceptions, ADR-0012).
- **Confidential** data never leaves its workspace and never reaches logs or error reports. The only third party that receives it is the AI provider, with the free-tier limit above.
- **Retention:** sessions end after 7 days; upload bytes are deleted after ingestion. Workspace deletion, and with it a full retention policy, is deferred (deletion is disabled until a data-retention flow exists).
