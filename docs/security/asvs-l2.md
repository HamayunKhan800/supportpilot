# OWASP ASVS 5.0.0 · Level 2 checklist

> M7 steps 2–5 · 2026-10-25 · Verdicts updated after the step 5 fixes · Source: [ASVS 5.0.0](https://github.com/OWASP/ASVS/tree/v5.0.0) (CSV export of the v5.0.0 release). Every Level 1 and Level 2 requirement (253) is listed with a verdict and its evidence. Evidence is a file, a test, a library source file checked in `node_modules` (better-auth 1.7.12), or a live check against the production build on 2026-10-25.
